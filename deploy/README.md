# Перенос сайта на сервер с ISPmanager (Ubuntu, MySQL, PHP)

## Что подготовлено
- `mysql_schema.sql` — структура таблиц + вся текущая продукция и услуги
- `api/config.php`, `api/products.php`, `api/services.php` — PHP-скрипты, отдающие данные
- `.htaccess` — чтобы прямые ссылки на страницы товаров/услуг открывались корректно
- `api.ts.for-own-server` — файл для замены src/lib/api.ts перед сборкой

## Шаги переноса

### 1. База данных
1. В ISPmanager: **Базы данных → Создать базу** (MySQL). Запишите имя базы, пользователя и пароль.
2. Откройте её через **phpMyAdmin** (кнопка рядом с базой в ISPmanager).
3. Импортируйте файл `mysql_schema.sql` — вкладка **Импорт**.

### 2. Скачивание кода сайта
1. В poehali.dev нажмите **Скачать → Подключить GitHub** (или **Скачать код**, если нужен просто архив).
2. Склонируйте/скачайте репозиторий себе на компьютер.

### 3. Подготовка кода перед сборкой
1. Замените содержимое `src/lib/api.ts` содержимым файла `deploy/api.ts.for-own-server`.
2. В корне проекта выполните:
   ```
   npm install
   npm run build
   ```
   Появится папка `dist` — это и есть готовый сайт.

### 4. Загрузка на сервер
1. В ISPmanager откройте **Файловый менеджер** для вашего домена.
2. Загрузите содержимое папки `dist` (не саму папку, а файлы внутри неё) в корень сайта (обычно `public_html` или `www`).
3. Загрузите файл `deploy/.htaccess` в тот же корень сайта.
4. Создайте папку `api` в корне сайта и загрузите туда `products.php`, `services.php`, `config.php`.

### 5. Настройка подключения к базе
1. Откройте `api/config.php` через файловый менеджер ISPmanager (редактирование файла).
2. Впишите туда имя базы, пользователя и пароль, которые получили в шаге 1.
3. Сохраните.

### 6. Проверка
Откройте в браузере:
- `https://ваш-домен.ру/api/products.php` — должен вернуться список товаров в формате JSON
- `https://ваш-домен.ру/api/services.php` — список услуг
- `https://ваш-домен.ру/catalog` — страница каталога на сайте

Если что-то не работает — пришлите мне текст ошибки, разберём вместе.

## Важно про форму заявок
Форма "Оставить заявку" на сайте пока никуда не отправляет данные (это отдельная функция,
которую можно подключить дополнительно — например, отправку на почту или в Telegram).
При переносе на свой сервер её тоже нужно будет реализовать через PHP отдельно.
